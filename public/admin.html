Danh Sách Gói Buff Chung Sức

ID Tên Gói Giá Tiền Mô Tả / Quyền Lợi Huy Hiệu (Badge) Thứ Tự Trạng Thái Thao Tác
1. Tên Miền Website (APP_URL) Đồng bộ .env

Đồng bộ tự động từ biến APP_URL trong file .env. Toàn bộ link Webhook bên dưới sẽ tự động cập nhật theo tên miền này.

💡 Gợi ý: Khi chạy thử ở máy tính thì để http://localhost:3000. Khi chạy thật trên VPS hoặc qua tên miền / Cloudflare Tunnel thì nhập URL thật (Ví dụ: https://yourdomain.com).
2. Cấu Hình Tài Khoản Ngân Hàng (VietQR Chuẩn NAPAS)

Tra cứu đúng mã ngân hàng VietQR (MB, VCB, ICB, TCB, VPB...)

3. Cấu Hình Telegram Bot Báo Đơn Thời Gian Thực

Tạo bot từ @BotFather trên Telegram

Lấy ID từ @userinfobot hoặc @RawDataBot

Được tự động cấu hình từ APP_URL trong .env. Bạn có thể sửa trực tiếp nếu muốn.

4. Webhook Thanh Toán Tự Động (SePay HMAC-SHA256)

Được tự động cấu hình từ APP_URL trong .env. Bạn có thể sửa trực tiếp hoặc chép dán vào SePay.

Chọn HMAC-SHA256 trong SePay. Secret Key được cấu hình riêng trên máy chủ bằng biến SEPAY_WEBHOOK_SECRET trong file .env; không nhập secret vào trang quản trị.
